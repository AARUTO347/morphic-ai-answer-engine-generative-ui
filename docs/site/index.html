About

Morphic is an AI-powered search engine that generates dynamic user interfaces in response to queries. It combines multiple search providers with large language models to deliver rich, interactive answers.

Screenshot

Features

Generative UI

AI-powered search that generates dynamic user interfaces in real-time based on your queries.

Search Modes

Quick mode for fast answers and Adaptive mode for deep research with follow-up questions.

Model Selector

Dynamic provider detection for OpenAI, Anthropic, Google, Ollama, and Vercel AI Gateway.

Chat History

All conversations stored in PostgreSQL with shareable unique URLs for each search.

File Upload

Upload documents and images for AI analysis alongside your search queries.

Auth & Guest Mode

Supabase authentication for registered users, guest mode for anonymous usage.

Providers

AI Providers

  • OpenAI (GPT-4, GPT-3.5)
  • Anthropic (Claude)
  • Google (Gemini)
  • Ollama (local models)
  • Vercel AI Gateway

Search Providers

  • Tavily (default)
  • SearXNG (self-hosted, included)
  • Brave Search
  • Exa (neural search)

Quick Start

git clone https://github.com/AARUTO347/morphic-ai-answer-engine-generative-ui.git cd morphic-ai-answer-engine-generative-ui bun install cp .env.local.example .env.local # Edit .env.local with your API keys bun dev

Visit http://localhost:3000

Docker

docker pull ghcr.io/miurla/morphic:latest # Or build from source: docker compose up -d

Docker Compose starts PostgreSQL, Redis, SearXNG, and Morphic automatically. No additional search API key needed.
